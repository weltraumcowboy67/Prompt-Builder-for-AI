# Prompt-Builder-for-AI

PromptWerk ist ein einfacher, moderner Prompt-Builder für KI-Anwendungen.

## Features

- Auswahl von Prompt-Typen (Text, Bild, Code, Lernen, Analyse)
- Dynamische Formularfelder je Typ
- Hilfetexte unter jedem Feld
- Live-Preview des fertigen Prompts
- Qualitäts-Feedback (fehlende Felder, Verbesserungstipps)
- Beispielwerte laden, Prompt verbessern, Prompt kopieren
- Lokale Speicherung per `localStorage`

## Start

Öffne die `index.html` direkt im Browser.
